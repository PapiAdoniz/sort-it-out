# Changelog

## 1.2.0 — October 23, 2026

Smart Place shows the destination and waits before it moves anything.

- Review every folder and move nothing until you confirm
- Leave a song with no artist tag unknown instead of naming it from a track number or a title-only lookup
- Keep a featured track with the album when the rest of that download belongs to one artist
- File songs dropped directly in the watch folder from their own tags
- Leave a file that is already in the library where it is, and give a different song with the same name a new filename
- Create a folder only when a song is about to move there, and remove it if that move fails

## 1.1.0 — October 23, 2026

Smart Place improvements for albums with featured artists and clearer MusicBrainz handling.

- File featured and minority tracks inside the main artist’s folder when most of the album belongs to one artist
- Count songs sitting directly in the watch folder when choosing the majority artist
- Use the album’s artist from MusicBrainz so a guest credit does not open its own top-level folder
- Share a matched release across the rest of a download when only some songs match MusicBrainz
- Retry lookups with cleaner titles and stop showing “no confident match” during the scan

## 1.0.0 — October 20, 2026

First release of Sort It Out for Mac.

- Scan folders and music files for artist, format, and quality without moving them
- Preview songs from the scan and from File Inspector
- File new downloads into a library with Smart Place, by artist or by artist and album
- Look songs up on MusicBrainz and save a matched release’s cover art
- Browse folders you care about with Folder Stalker
- Choose a dark color theme
